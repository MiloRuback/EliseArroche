Contexto

Por que acessibilidade importa?

Mais de 1 bilhão de pessoas no mundo vivem com algum tipo de deficiência — e a web precisa funcionar para todas elas.

01

É uma questão de pessoas

Pessoas com baixa visão, surdez, mobilidade reduzida ou deficiência cognitiva precisam de adaptações para navegar. Sem elas, ficam de fora.

02

É uma obrigação legal

No Brasil, a Lei Brasileira de Inclusão (Lei 13.146/2015) exige acessibilidade em sites. Empresas podem ser multadas por descumprimento.

03

É mais fácil do que parece

As 6 bibliotecas que veremos a seguir resolvem problemas reais de acessibilidade em poucas linhas de código — sem reinventar a roda.

03 / 12
Conceito

O que são bibliotecas JavaScript?

Conjuntos de código pronto que economizam tempo e adicionam funcionalidades prontas para uso.

1

HTML — estrutura

Define o que aparece na página: botões, textos, imagens e a organização dos elementos.

2

CSS — aparência

Define como a página se parece: cores, tamanhos, posições, animações visuais.

3

JavaScript — comportamento

Adiciona interatividade: cliques, validações, animações, comunicação com servidores.

4

Bibliotecas JS — soluções prontas

Oferecem comportamentos específicos já prontos: animações, gráficos, modais, carrosséis, validação de formulários etc.

04 / 12
Mão na massa

Como incluir uma biblioteca no HTML

O mesmo padrão serve para todas as 6 bibliotecas — só muda o endereço e a função.

index.html — exemplo com canvas-confetti
<html>
  <head>
    <style>
      body, html {
        margin: 0;
        padding: 0;
        width: 100%;
        height: 100%;
      }
    </style>

    <!-- 1. Importa a biblioteca via CDN -->
    <script src="https://cdn.jsdelivr.net/npm/canvas-confetti@1.9.3/dist/confetti.browser.min.js"></script>

    <!-- 2. Usa a função confetti() -->
    <script>
      confetti();
    </script>
  </head>

  <body>
    <h1>Texto de Exemplo 🎉</h1>
  </body>
</html>

check_circle Passo a passo

  1. Importar via tag <script src>
  2. Chamar a função que a biblioteca expõe
  3. Pronto! O comportamento está disponível

O mesmo padrão de importar e chamar vale para todas as 6 bibliotecas que veremos a seguir.
